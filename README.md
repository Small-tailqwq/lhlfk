## 项目简介

针对拉海诺方块（8×8 棋盘方块消除类游戏）的全自动辅助工具，具备以下能力：

- **CV 视觉识别**：截图棋盘与预备区，通过 HSV 颜色空间自动识别当前盘面与待放方块形状。
- **JIT 加速博弈求解**：使用 Numba 编译的暴力搜索，在所有 4! = 24 种放置顺序下穷举最优落子位置，并通过多维启发式评估函数指导选择。
- **自动执行**：调用鼠标注入后端（pydirectinput / pyautogui），将求解结果自动拖拽执行到游戏中。
- **Agent 循环模式**：自动循环识别→求解→执行，支持热键随时停止。
- **Web 控制台**：提供单页面 UI（`index.html`），可手动录入棋盘/方块、查看回放步骤、触发 CV 识别及执行。

## 技术架构

```
index.html          ← 单页面前端，浏览器直接打开
    │  HTTP (localhost:8000)
    ▼
app.py              ← FastAPI 后端，路由 / 算法 / Agent 循环
    ├── vision_core.py   ← OpenCV 视觉引擎（截图、HSV 检测、坐标映射）
    └── executor.py      ← 鼠标注入执行器（拖拽时序、锚点计算）
```

### 核心文件说明

| 文件 | 职责 |
|------|------|
| `app.py` | FastAPI 应用主体；包含 Numba JIT 编译的求解算法（`_solve_turn`）、Agent 循环线程、所有 REST API 端点、性能日志记录 |
| `vision_core.py` | 屏幕区域框选（Tkinter 独立进程）；棋盘识别（HSV 饱和度+亮度阈值、逐格 fill-ratio 判断）；预备区方块识别（轮廓聚类、细长块分裂、垂直行补全） |
| `executor.py` | 鼠标拖拽逻辑（分步平滑移动）；锚点选择算法（根据块形状确定最优抓取格）；三种时序档位（safe / balanced / fast） |
| `index.html` | 前端 UI；8×8 棋盘交互绘制；方块图鉴库与队列槽位管理；Agent 模式控制面板；回放步骤演算 |

## 求解算法

采用**深度优先全排列穷举 + 剪枝 + 启发式评估**：

1. 枚举 4 个方块的所有 24 种放置顺序（`PERMS_4`）。
2. 对每种顺序逐块枚举所有合法落点（8×8 = 64 格），检测碰撞并模拟消除得分。
3. 空盘时启用**锚点剪枝**（要求方块与已有方块或边界相邻），显著缩小搜索空间。
4. 对最终盘面执行多维启发式评估：
   - 负向：空洞数、过渡边数、孤块、棋盘过空
   - 正向：接近满行/列数
   - 战术分：按空格数动态调整连消奖励策略
5. 整个搜索循环由 Numba `@njit` 编译为机器码，典型求解耗时 **< 100 ms**。

## 环境要求

- **操作系统**：Windows（依赖 `ctypes.windll`、`win32api` 等 Windows API）
- **Python**：3.10+
- **管理员权限**：执行器在向管理员权限游戏进程注入鼠标事件时**必须以管理员身份启动**

### 依赖安装

```bash
pip install fastapi uvicorn numpy numba opencv-python pillow pydantic pydirectinput pyautogui
```

> `pydirectinput` 为首选鼠标后端（直接发送 Win32 SendInput），`pyautogui` 作为回退。

## 快速上手

### 1. 以管理员身份启动后端

```bash
# 在管理员权限的终端中执行
python app.py
```

后端默认监听 `http://localhost:8000`。

### 2. 打开前端

直接用浏览器打开项目目录下的 `index.html`。

### 3. 框选游戏区域

- 点击「**框选预备区**」→ 用鼠标框选游戏中展示待放方块的区域
- 点击「**框选棋盘**」→ 框选 8×8 主棋盘区域
- 框选结果自动保存到 `app_settings.json`，下次启动无需重复框选

### 4. 识别与求解

- 点击「**识别预备区**」→ CV 引擎截图并识别当前 4 个方块，自动填入队列
- 点击「**识别棋盘**」→ 识别当前棋盘状态并填入主棋盘
- 点击「**AI 求解**」→ 计算最优落子方案并进入回放模式

### 5. Agent 全自动模式

在 Agent 面板中设置等待间隔与停止热键（默认 F8），点击「**启动 Agent**」后程序将自动循环执行，直到按下停止热键或棋盘无解。

## 执行器时序档位

| 档位 | 适用场景 | 稳定性 |
|------|----------|--------|
| `safe` | 低帧率/高延迟环境，首选 | 最高 |
| `balanced` | 日常使用 | 中等 |
| `fast` | 追求速度，可能漏收事件 | 较低 |

## 调试功能

- **调试截图**：识别结果自动以 `cv_capture_1~3.png` 轮转保存在项目根目录
- **tmp 中间图**：在设置中勾选「输出识别过程图像到 tmp 目录」可查看每步 HSV 处理细节
- **性能日志**：勾选「性能分析模式」后，各环节耗时（毫秒级）记录到 `dataset/perf_log.jsonl`
- **对局记录**：每轮求解结果（棋盘+方块+步骤）自动追加到 `dataset/turn_history.jsonl`
  - **记得清理，文件不小**

## REST API 概览

| 端点 | 方法 | 说明 |
|------|------|------|
| `/solve` | POST | 传入棋盘+4块，返回最优落子步骤 |
| `/api/set_bbox` | GET | 触发屏幕框选（预备区） |
| `/api/set_board_bbox` | GET | 触发屏幕框选（棋盘） |
| `/api/auto_recognize` | GET | CV 识别预备区方块 |
| `/api/recognize_board` | GET | CV 识别棋盘状态 |
| `/api/execute_solution` | POST | 执行给定步骤的鼠标拖拽 |
| `/api/agent/start` | POST | 启动 Agent 自动循环 |
| `/api/agent/stop` | POST | 停止 Agent |
| `/api/agent/status` | GET | 查询 Agent 当前状态 |
| `/api/settings` | GET/POST | 读写持久化设置 |
